NekoDroid ships with five bare-metal ARM demo programs in C. Each exercises different parts of the emulator. All run at physical address `0x8000` without an operating system.

## Prerequisites

Install the `arm-none-eabi-gcc` cross-compiler:

```bash
# Ubuntu
sudo apt-get install gcc-arm-none-eabi binutils-arm-none-eabi

# macOS
brew install --cask gcc-arm-embedded
```

## Build all demos

From the repo root:

```bash
# Hello UART
arm-none-eabi-gcc -nostdlib -nostartfiles -Ttext=0x8000 \
  -mcpu=arm7tdmi -marm -O2 -o hello.elf start.S main.c
arm-none-eabi-objcopy -O binary hello.elf hello.bin

# VRAM test
arm-none-eabi-gcc -nostdlib -nostartfiles -T link.ld \
  -mcpu=arm7tdmi -marm -O2 -o vram_test.elf start.S vram_test.c
arm-none-eabi-objcopy -O binary vram_test.elf vram_test.bin

# Input test
arm-none-eabi-gcc -nostdlib -nostartfiles -T link.ld \
  -mcpu=arm7tdmi -marm -O2 -o input_test.elf start.S input_test.c
arm-none-eabi-objcopy -O binary input_test.elf input_test.bin

# Snake
arm-none-eabi-gcc -nostdlib -nostartfiles -Ttext=0x8000 \
  -mcpu=arm7tdmi -marm -O2 -o snake.elf start.S snake.c
arm-none-eabi-objcopy -O binary snake.elf snake.bin

# Theremin
arm-none-eabi-gcc -nostdlib -nostartfiles -Ttext=0x8000 \
  -mcpu=arm7tdmi -marm -O2 -o theremin.elf start.S theremin.c
arm-none-eabi-objcopy -O binary theremin.elf theremin.bin
```

`start.S` is a single branch to `_start`. `link.ld` places sections at `0x8000` and preserves `.rodata` and `.bss`.

## Hello UART (`main.c`)

Writes two lines to the virtual UART at `0x10000000` and halts.

```c
volatile unsigned char * const UART_TX = (unsigned char *)0x10000000;

void print_string(const char *str) {
    while (*str) *UART_TX = *str++;
}

void _start() {
    print_string("Hello from Bare-Metal C running on NekoDroid!\n");
    print_string("If you are reading this, your ARM CPU is fully functional.\n");
    while (1) {}
}
```

Build, load `hello.bin` into the emulator, and run. Output appears in the browser console.

## VRAM test (`vram_test.c`)

Draws three 100x100 colored squares and confirms via UART.

```c
volatile unsigned int * const VRAM = (unsigned int *)0x04000000;
volatile unsigned char * const UART_TX = (unsigned char *)0x10000000;

#define WIDTH  800
#define HEIGHT 600

void fill_rect(int x0, int y0, int x1, int y1, unsigned int color) {
    for (int y = y0; y < y1; y++)
        for (int x = x0; x < x1; x++)
            VRAM[y * WIDTH + x] = color;
}

void _start(void) {
    fill_rect(100, 100, 200, 200, 0xFF0000FF); // red
    fill_rect(250, 100, 350, 200, 0xFF00FF00); // green
    fill_rect(400, 100, 500, 200, 0xFFFF0000); // blue

    const char *msg = "VRAM test complete: RGB squares drawn!\n";
    while (*msg) *UART_TX = *msg++;
    while (1) {}
}
```

Colors are little-endian RGBA. `0xFF0000FF` means red=0xFF, alpha=0xFF.

## Input test (`input_test.c`)

Polls keyboard, touch, and timer registers and draws a live UI.

Features:

- Key display: bar width proportional to keycode
- Touch cursor: crosshair following mouse or finger
- Timer bar: grows with the frame counter
- Trail dots: magenta dots where you have touched

```c
volatile unsigned int * const VRAM       = (unsigned int *)0x04000000;
volatile unsigned char * const UART_TX   = (unsigned char *)0x10000000;
volatile unsigned int * const INPUT_KEY  = (unsigned int *)0x10000008;
volatile unsigned int * const INPUT_TOUCH= (unsigned int *)0x1000000C;
volatile unsigned int * const INPUT_COORD= (unsigned int *)0x10000010;
volatile unsigned int * const SYS_TIMER  = (unsigned int *)0x10000014;
```

Load, switch to VRAM mode, run. Press keys and drag on the canvas.

## Snake (`snake.c`)

A grid-based Snake game using VRAM, keyboard input, the VSYNC timer, and audio.

Features:

- 40x30 grid, each cell 19x19 pixels with 1-pixel gap
- Arrow keys change direction. 180-degree reversal is blocked.
- Updates every 4 timer ticks
- 600 Hz square wave beep when eating food. 150 Hz tone on game over.
- Incremental render: only old tail and new head cells redrawn

Minimal libc stubs included:

```c
void *memmove(void *dest, const void *src, unsigned int n) { ... }
unsigned int __aeabi_uidivmod(unsigned int num, unsigned int den) { ... }
```

| Color | Value | Usage |
| --- | --- | --- |
| `COLOR_BG` | `0xFF111111` | Empty cells |
| `COLOR_SNAKE` | `0xFF00FF00` | Snake body |
| `COLOR_HEAD` | `0xFF88FF88` | Snake head |
| `COLOR_FOOD` | `0xFF0000FF` | Food |
| `COLOR_DEAD` | `0xFF4444FF` | Flash on collision |

Load `snake.bin`, switch to VRAM mode, run. Press arrow keys to steer. Press any arrow key after game over to restart.

## Theremin (`theremin.c`)

Touch-controlled synthesizer mapping position to pitch and waveform.

```c
volatile unsigned int * const INPUT_TOUCH = (unsigned int *)0x1000000C;
volatile unsigned int * const INPUT_COORD = (unsigned int *)0x10000010;
volatile unsigned int * const AUDIO_CTRL  = (unsigned int *)0x10000018;
volatile unsigned int * const AUDIO_FREQ  = (unsigned int *)0x1000001C;

void _start(void) {
    while (1) {
        if (*INPUT_TOUCH == 1) {
            unsigned int coords = *INPUT_COORD;
            unsigned int x = coords & 0xFFFF;
            unsigned int y = (coords >> 16) & 0xFFFF;
            *AUDIO_FREQ = 100 + x;
            unsigned int wave_type = (y / 150) & 3;
            *AUDIO_CTRL = 1 | (wave_type << 1);
        } else {
            *AUDIO_CTRL = 0;
        }
    }
}
```

X axis controls pitch (100 to 900 Hz). Y axis changes waveform: `0` square, `1` sine, `2` sawtooth, `3` triangle. Release to silence.

Web Audio requires a user gesture. The first canvas click initializes the `AudioContext`.

## Linker script (`link.ld`)

```ld
ENTRY(_start)

SECTIONS {
    . = 0x8000;
    .text : {
        *(.text._start)
        *(.text.startup)
        *(.text*)
    }
    .rodata : { *(.rodata*) }
    .data   : { *(.data*)   }
    .bss    : { *(.bss*)    }
}
```

Places boot code at `0x8000`, matching the emulator reset vector.

## Startup assembly (`start.S`)

```asm
.section .text.boot, "ax"
.global _boot
_boot:
    b _start
```

Two instructions: branch to C entry point.

## Running in the UI

1. Build the Wasm module: `wasm-pack build --target web`
2. Start the dev server: `npm run dev`
3. Open the UI and click **Select & Load .bin**
4. For graphics demos, switch to **VRAM** mode
5. Click **Run**

The CPU executes instructions each frame. Pause, step, or inspect registers in the debug panel.

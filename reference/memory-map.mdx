NekoDroid maps the ARMv7 address space into a flat, byte-addressable layout. This page lists every region with base address and size verified from `src/memory.rs`.

## Address space layout

| Region | Base | Size | Purpose |
| --- | --- | --- | --- |
| RAM | `0x00000000` | configurable, default 512 MiB, max 4096 MiB | Main system memory |
| VRAM | `0x04000000` | 1,920,000 bytes | 800x600 RGBA framebuffer |
| Custom MMIO | `0x10000000` | 32 bytes | UART, input, timer, audio |
| Binder IPC | `0x0A000000` | 1 MiB | Android Binder driver stub |
| VersatilePB window | `0x10100000` | 1 MiB | Board-specific peripherals |
| Goldfish RTC | `0x10101000` | 4 KiB | Real-time clock |
| PL190 VIC | `0x10140000` | 4 KiB | Vectored Interrupt Controller |
| SP804 Timer | `0x101E2000` | 32 bytes | Dual timer module |
| PL011 UART0 | `0x101F1000` | 4 KiB | Serial console for Linux earlyprintk |
| ASHMEM | `0x1B000000` | 64 KiB | Anonymous shared memory stub |
| MMC | `0x1C000000` | 64 KiB | SD/MMC card interface |
| Goldfish Pipe | `0x1D000000` | 1 MiB | Host-guest communication |
| Android Logger | `0x1E000000` | 64 KiB | Logcat interface |
| Goldfish FB | `0x1F000000` | 16 MiB | Framebuffer config |
| Goldfish TTY | `0xFF002000` | 4 KiB | Earlyprintk console |

Writes to unmapped addresses are silently ignored. Reads return `0`.

## RAM configuration

Call `init_emulator(ram_mb)` before loading a program.

| Parameter | Behavior |
| --- | --- |
| `0` | Default 512 MiB |
| `1` to `4096` | Allocates requested megabytes |
| `> 4096` | Hard-capped to 4096 MiB |
| `> 1024` | Warning logged about browser OOM risk |

After initialization:

| Register | Value |
| --- | --- |
| PC | `0x00008000` |
| SP | `ram_size - 0x10000` |

The 32 MiB soft cap applies to APKs loaded through the UI, not to `load_rom`.

## VRAM pixel format

The framebuffer at `0x04000000` stores pixels in RGBA8888 (32 bits per pixel) in row-major order.

| Byte offset | Channel |
| --- | --- |
| +0 | Red |
| +1 | Green |
| +2 | Blue |
| +3 | Alpha (0xFF = opaque) |

Total size: `800 * 600 * 4 = 1,920,000` bytes. Last valid address: `0x041D4BFF`.

VRAM initializes to black with full alpha on `init_emulator` and `load_rom`.

```c
#define VRAM_BASE 0x04000000
#define SCREEN_W  800

void put_pixel(int x, int y, unsigned char r, unsigned char g, unsigned char b) {
    volatile unsigned char *vram = (unsigned char *)VRAM_BASE;
    int off = (y * SCREEN_W + x) * 4;
    vram[off + 0] = r;
    vram[off + 1] = g;
    vram[off + 2] = b;
    vram[off + 3] = 0xFF;
}
```

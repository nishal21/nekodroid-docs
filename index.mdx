Run small Android APKs in your browser.

NekoDroid runs supported DEX bytecode locally with a constrained Dalvik runtime. It also emulates ARM and Thumb programs. No server executes your programs. The documented setup requires a local build; this is not a full Android environment.

## Try the Hello Fixture

Build NekoDroid, select `testdata/hello.apk` with **Load APK**, then click **Run APK (HLE)**. The HLE log should contain:

```text Hello fixture output
Hello from NekoDroid
```

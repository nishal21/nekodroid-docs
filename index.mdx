  <div className="nd-doc-section">
    <h2 className="nd-doc-section-title">Up and running</h2>

    <Steps>
      <Step title="Install the tools">
        Stable Rust with `wasm32-unknown-unknown`, wasm-pack, and Node.js `^20.19.0` or `>=22.12.0`.

        ```bash
        rustup target add wasm32-unknown-unknown
        ```
      </Step>

      <Step title="Clone and install">
        ```bash
        git clone https://github.com/nishal21/NekoDroid.git
        cd NekoDroid
        npm install
        ```
      </Step>

      <Step title="Build and start">
        <CodeGroup>
          ```bash Build Wasm
          wasm-pack build --target web
          ```

          ```bash Dev server
          npm run dev
          ```
        </CodeGroup>

        Open [http://localhost:5173](http://localhost:5173).
      </Step>

      <Step title="Try it">
        <Tabs>
          <Tab title="ARM demo">
            In **ARMv7 CPU Debug**, click **Load Demo**, then **Step**. After three steps, `R0`, `R1`, and `R2` hold `5`, `10`, and `15`.
          </Tab>

          <Tab title="Hello APK">
            Click **Load APK**, pick `testdata/hello.apk`, then **Run APK (HLE)**. The log shows:

            ```text
            Hello from NekoDroid
            ```
          </Tab>
        </Tabs>
      </Step>
    </Steps>
  </div>

  <div className="nd-doc-section">
    <h2 className="nd-doc-section-title">Good to know</h2>

    <AccordionGroup>
      <Accordion title="Can it run Play Store apps?">
        No. Multidex, JNI, and Google Play Services are out of scope. See [Supported APKs](/android/supported-apks).
      </Accordion>

      <Accordion title="Does execution leave the browser?">
        No. Everything runs locally through WebAssembly.
      </Accordion>

      <Accordion title="Do APKs run on the ARM CPU?">
        No. ARM and Dalvik are separate runtimes. Read [How it works](/how-it-works).
      </Accordion>
    </AccordionGroup>
  </div>

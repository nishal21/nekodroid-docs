This page takes you from a fresh clone to a running NekoDroid emulator in your browser. You will build the Rust WebAssembly module, start the dev server, and verify the setup with the built-in ARM demo.

## Prerequisites

Before you start, install these tools:

- Rust stable with the `wasm32-unknown-unknown` target
- wasm-pack
- Node.js `^20.19.0` or `>=22.12.0`, required by Vite in the lockfile

Run `rustup target add wasm32-unknown-unknown` after installing Rust. For detailed install steps, see the [Installation](/installation) guide.

## Build and Launch

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/nishal21/NekoDroid.git
    cd NekoDroid
    ```
  </Step>
  <Step title="Install Node dependencies">
    ```bash
    npm install
    ```

    This installs Vite 7.3.1, TypeScript 5.9.3, and the Wasm loader plugins.
  </Step>
  <Step title="Build the Wasm module">
    ```bash
    wasm-pack build --target web
    ```

    This compiles the Rust crate into `pkg/nekodroid.js` and `pkg/nekodroid_bg.wasm`.
  </Step>
  <Step title="Start the dev server">
    ```bash
    npm run dev
    ```

    Open your browser to [http://localhost:5173](http://localhost:5173). You should see the NekoDroid UI with the canvas, mode buttons, and debug panel.
  </Step>
</Steps>

## Verify Your Setup

Choose either path below to confirm the emulator is working.

<Tabs>
  <Tab title="ARM Demo">
    The fastest way to verify the CPU is to load the built-in demo and step through it.

    <Steps>
      <Step title="Load the demo">
        In the **ARMv7 CPU Debug** panel, click **Load Demo**. This writes 10 ARM instructions at address `0x8000` and resets `PC` to the same address.
      </Step>
      <Step title="Step through instructions">
        Click **Step** repeatedly and watch the register grid update:

        | Step | Instruction | Result |
        | --- | --- | --- |
        | 1 | `MOV R0, #5` | `R0 = 00000005` |
        | 2 | `MOV R1, #10` | `R1 = 0000000A` |
        | 3 | `ADD R2, R0, R1` | `R2 = 0000000F` |

        After three steps, registers `R0`, `R1`, and `R2` hold `5`, `10`, and `15`.
      </Step>
      <Step title="Run continuously">
        Click **Run** to execute instructions in batches. The cycle count updates in the metrics panel. Click **Stop** to pause.
      </Step>
    </Steps>
  </Tab>
  <Tab title="hello.apk Fixture">
    The `testdata/hello.apk` file is a minimal APK fixture for the HLE Dalvik runtime.

    <Steps>
      <Step title="Load the APK">
        1. In the UI, scroll to the **APK (HLE DEX)** section.
        2. Click **Load APK** and select `testdata/hello.apk` from your local filesystem.
      </Step>
      <Step title="Run the APK">
        Click **Run APK (HLE)**. The emulator launches the Dalvik VM, runs up to 50,000 steps, and switches the display to VRAM mode.
      </Step>
      <Step title="View output">
        The logcat panel shows `Hello from NekoDroid`. The display switches to VRAM automatically.
      </Step>
    </Steps>

    To regenerate the fixture from source, run `cargo test --lib write_fixtures_to_testdata`.
  </Tab>
</Tabs>

## Troubleshooting

If the dev server starts but the page shows a Wasm error, make sure you ran `wasm-pack build --target web` and that `pkg/nekodroid_bg.wasm` exists.

If the register grid does not update when you click Step, check the browser console for Rust panic messages. Refresh after confirming the build succeeded.
